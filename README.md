# 🎉 Welcome Card React

A modern and responsive greeting card website built with React and Vite.

## Features

- 🎂 Featured greeting cards
- 💍 Multiple card categories
- ⭐ Customer reviews
- 💙 Why Choose Us section
- 🎨 Modern UI

## Technologies Used

- React
- Vite
- CSS3
- Font Awesome
